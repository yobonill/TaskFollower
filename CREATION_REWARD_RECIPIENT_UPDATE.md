# Creation reward recipient correction

- The +2 Papipuntos manual-task creation bonus is no longer awarded when the task is saved.
- It is awarded when the task is completed, to the user who actually completes it.
- For tasks assigned to Ambos, both users receive the +2 bonus, matching shared-task reward behavior.
- Imported, duplicated, recurring-generated, and migrated tasks still do not receive this bonus.
- Undoing a completion removes the completion-time creation bonus as well.
- Legacy unfinished tasks that already have the old immediate creation transaction are reconciled when they are completed.
